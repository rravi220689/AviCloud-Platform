Client Mount Instructions

Linux Client Mount: 
sudo mkdir -p /mnt/avicloud && sudo mount -t nfs -o port=2049,mountport=2049,nfsvers=3,nolock 127.0.0.1:/storage /mnt/avicloud
macOS Client Mount: 
sudo mkdir -p /Volumes/AviCloud && sudo mount_nfs -o port=2049,mountport=2049,vers=3,nolock 127.0.0.1:/storage /Volumes/AviCloud
Windows Client Mount (Map Network Drive): 
mount -o anon,nolock \\127.0.0.1\storage Z:
